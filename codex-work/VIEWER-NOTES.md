# 청용리 작은집 뷰어

`intels`의 도면·사진·GEO-NOTE만 직접 읽어 만든 독립 구현입니다. 각 HTML에 설계 데이터, 스타일, 편집 기능과 3D 생성 코드가 들어 있습니다. 빌드는 필요하지 않습니다.

## 열기

현재 이 호스트의 로컬 미리보기:

- 공간 설계: http://127.0.0.1:8774/codex-work/house-plan.html
- 현장 시뮬레이션: http://127.0.0.1:8774/codex-work/site-sim.html

미리보기 서버를 다시 시작하려면:

```sh
python3 /home/ancom/workspace/10pyeong-house/codex-work/serve-viewers.py
```

이 서버는 두 HTML과 `intels` 자료만 제공합니다. Three.js 0.169.0 CDN과 IBM Plex Sans KR 폰트에는 인터넷 연결이 필요합니다. 직접 파일로 열 수도 있으나 두 페이지 사이의 저장안 공유에는 같은 HTTP 주소를 사용하세요. 자료 보기의 사진·도면은 `../intels` 상대 경로입니다.

## 공간 설계

- 1층/다락 층 선택, 2D/3D 전환, 지붕 열기, 조감도와 1인칭 이동.
- 실제 mm 치수의 기본 가구. 드래그 이동, 모서리 크기 조절, 치수 입력, 15° 회전, 벽 80mm 이내 맞춤.
- 두 점 측정, 비내력 가벽 추가·이동·두께 변경·철거, 연결 벽 접합 유지, 방 순면적 재계산과 바닥 마감 변경.
- 실행 취소/다시 실행, 브라우저 로컬 저장과 새로고침 복원, 2D·3D PNG 내보내기.
- `R` 회전, `Delete` 삭제, `Ctrl+Z` 취소, `Ctrl+Shift+Z` 다시 실행, `Ctrl+S` 저장.
- 1인칭은 WASD/방향키 및 화면 드래그. 모바일은 화면 드래그와 이동 버튼, 2D는 두 손가락 확대. 계단으로 층이 연결되며 보이드와 난간·가구·벽의 통행을 제한합니다.

## 현장 시뮬레이션

7단계: 빈 대지 → 기초·형틀·철근·타설 → 1층 경량철골 → **다락 골조 상승(현재)** → 지붕 → 외장 → 창호·조경·완공.

현재 표시는 2026-10-04 사용자 확정과 사진 17~21 기준입니다. 1층 골조가 완성·고정되었으며 다락 기둥과 상부 트러스가 완성 높이까지 올라온 상태입니다. 기초 이력은 사진 1~16으로 구분합니다. 기초와 타설을 한 단계 안에 묶어 7단계를 유지했습니다.

건물과 기초는 같은 축이고 정면은 동쪽입니다. 남·동쪽 논, 남쪽 곡선 도로와 진입로, 북·서쪽 산림, 기존 옹벽·돌담·마을·전봇대·가로등을 재해석했습니다. 단계 전환 애니메이션, 자동 순항, 시간대와 그림자 변화, 궤도/1인칭, 마당 비교안과 조경 미리보기를 제공합니다. 완공 단계는 공간 설계의 저장안을 사용합니다.

마당 기본안은 판석+잔디와 투수 블록 주차부입니다. 동향 정면에서 바라본 건물 좌측, 즉 남쪽에 비석과 두 주목을 두었습니다. 담장 주변의 산수유·라일락·비파·무화과·체리, 북쪽 녹차 생울타리는 사용자 희망을 반영한 배치 후보입니다.

## 치수와 판단 근거

- `plans/floorplan-1f.jpg`: 7,400 → **8,000mm** 수정, 깊이 **4,500mm**, 외벽 **100mm**, 오른쪽 **3,000mm**, 욕실 깊이 **1,400mm**, 좌측 볼펜 후문.
- 가로 분할은 2,600 / 2,200 / 3,000mm와 양쪽 외벽으로 정리했습니다. 인쇄 숫자와 수정 숫자만으로 세부 분할이 완전히 닫히지 않아 가운데 2,200mm는 해석값입니다.
- 손그림 후면 3m는 폭 8m 후면 확장 계획으로 해석했습니다. 다락 3,000 × 3,300mm 증축은 북측 별도 계획입니다. 두 옵션은 기본 켜짐이며 현재 공사 단계에서는 완공 계획으로 구분됩니다.
- `plans/floorplan-attic.jpg`: 거실 위 VOID는 실제 바닥 구멍입니다. 다락과 보이드 사이에 벽을 두지 않고 난간으로 보호했습니다. 900mm 폭, 14단 계단, 상부 출입 틈과 계단 옆 통로를 모델링했습니다.
- `plans/elevation-front.jpg`: 1층 **2,300mm**, 다락 **1,800mm**를 사용했습니다. 박공 용마루 **4,950mm**, 난간 **1,100mm**, 계단 상세, 문폭·창폭, 세부 가구·확장 배치는 제안값입니다. 창·문은 사진과 도면의 개구부를 직접 해석했습니다.
- `references/건축허가도면.jpg`는 배치 계획, `references/건물-비석.jpg`는 상대 위치, `references/지붕.jpg`는 마감 참고로 사용했습니다. 지붕의 박공 형상은 최신 골조 사진을 우선했습니다.
- 지형 윤곽·성토·배수와 약 55m 펜스+약 20m 북쪽 녹차는 모델 배치 예시입니다. 측량 경계·실제 둘레·수종 생육 적합성을 확정한 값이 아닙니다.
- 구조 보호벽은 편집 잠금 분류입니다. 제공 자료만으로 실제 내력 여부를 확정할 수 없으므로 외곽 철골을 보수적으로 보호했습니다.

각 페이지의 ⓘ 버튼에서 원본 자료와 같은 판단 설명을 볼 수 있습니다.

## 검증

Chromium 헤드리스 WebGL과 390 × 844 모바일 터치 에뮬레이션으로 검증했습니다. 실제 휴대전화나 현장 실측을 사용한 검증은 포함하지 않습니다.

가구 이동·회전·리사이즈·벽 맞춤, 측정, 가벽 이동/접합/철거와 면적 계산, 마감 변경, 취소/복구, 저장 복원, PNG, 두 페이지 저장 이벤트, 7단계, 자동 순항, 태양·그림자, 마당 비교, 모바일 층·단계·두 손가락 확대, CDN 실패 복구를 확인했습니다. 실제 3D 메시의 수직 광선으로 보이드 위 바닥 부재와 다락 바닥 높이 2.3m를 확인했고 계단 상부의 난간 출입 틈도 검사했습니다. 기본 가구 간섭 검사와 실제 이동 함수를 사용한 거실→욕실→침실, 1층↔다락, 현장 완공 모델의 다락 높이까지 검증했습니다.

검증 기록과 미리보기 이미지는 `viewer-verification/`에 있습니다. 최종 치수·동선 검증 기록의 SHA-256이 두 HTML의 최종 파일에 대응합니다.

검증을 재현하려면 미리보기 서버를 실행한 뒤 Playwright가 설치된 Python으로 다음 중 필요한 검증을 실행할 수 있습니다.

```sh
/home/ancom/miniconda3/bin/python /home/ancom/workspace/10pyeong-house/codex-work/viewer-verification/check-routes.py
/home/ancom/miniconda3/bin/python /home/ancom/workspace/10pyeong-house/codex-work/viewer-verification/check-mobile-and-recovery.py
```

`qa-routes.json`은 최종 HTML의 치수·물리 동선·메시·모바일 화면 검증 결과이고, 나머지 기록은 변경하지 않은 기능의 재사용한 검증 근거입니다.
